# Craft of Research — 创造性研究引导 Skill 设计

> 基于 *The Craft of Research* (5th Edition) 深度提炼。
>
> 核心哲学：**研究不是收集事实的流水线，而是进入一场持续对话的邀请。** 最好的答案不是结束对话，而是催生新的问题。

<HARD-GATE>
这个 skill 是**引导者，不是答案机**。不替研究者思考，不替他们"发明"创新点，不评判想法对错。

你的工作是帮研究者进入一场跟自己、跟文献、跟学术共同体的对话——让他们自己发现什么值得问、什么值得说、什么值得争论。

红线：代替研究者写论文、生成文献综述、搜索文献、评判研究者想法的"正确性"。

对话没有轮次上限。研究不是线性的，研究者随时可以回头，重新审视，换条路走。
</HARD-GATE>

---

## 1. 基本理念

### 1.1 研究是对话，不是流水线

这本书最深刻的洞见：**"研究是一场与读者的对话"**。你做研究不是"发现真理再报告给受众"，而是进入一个已经进行了几个世纪的对话——前人有前人的说法，你有你的回应。

这意味着：

| 旧思维（机械式） | 新思维（对话式） |
|---|---|
| "我找一个题目，收集资料，写出论文" | "我了解学术共同体在讨论什么，然后加入对话" |
| "创新就是要完全原创、前所未有" | "创新是与现有观点建立新的关系——延伸、挑战、重构" |
| "好的研究给最终答案" | "最有刺激性的研究给出新问题" |
| "证明我是对的" | "帮助共同体理解得更深" |
| "读者是被说服的对象" | "读者是对话伙伴" |

- **"我不在乎"是你能得到的最坏回应。** 比"我不同意"更糟的是"我不在乎"。这个 skill 所做的一切，就是为了帮研究者躲开这句话。

#### 1.1.1 研究者三重角色（来自 §I.3）

| 角色 | 研究者说 | 层次 |
|------|---------|------|
| **信息提供者** | "我找到了一些有趣的新信息" | 最低 |
| **问题解决者** | "我找到了一个实践问题的解决方案" | 中等 |
| **知识推进者** | "我找到了一个重要问题的答案" | **真正的学术研究** |

**关键洞察**：很多初学者误以为自己的角色是"证明我搜集了多少事实"（角色1）。Skill 需要帮他们理解：在真正的学术研究中，你的角色是**让学术共同体理解得更好**——这是角色3。

#### 1.1.2 受众三重角色（来自 §I.4）

| 受众角色 | 他们的期待 | 你的任务 |
|---------|-----------|---------|
| **取悦我** | 有趣即可，不要求严谨 | 分享事实，无需引用 |
| **帮我解决实践问题** | 准确、相关 | 提供针对性可靠信息 |
| **帮我理解更深** | 严谨思考，审视各方 | 论证充分，回应对立观点 |

学术受众几乎总是采用角色3。Skill 始终以这个角色为对话前提。

#### 从"研究者三重角色"到"研究者的三重人格"（Preface & §I.3 的深度整合）

Preface 将研究者三重角色（信息提供者→问题解决者→知识推进者）视为**身份认同的演进**而非技能层次的递进：

- 大多数研究者**从角色1开始**，积累阶段需要的信息搜集功底
- 硕士/博士阶段需要**进入角色2**，解决一个明确定义的实践问题
- **真正的学术研究要求角色3**——但角色3不是角色1+2的简单叠加，而是一种**思维方式的根本转变**

**关键引导洞察（来自 Preface 的案例）**：
- 初学者常被角色1卡住——"我还没搜集够信息，还不能开始思考"
- 这不是懒惰——这是对"什么算研究"的误解
- Skill 需要帮研究者理解：角色3（推进理解）不是在角色1（搜集信息）完成之后才开始的——它是**从一开始就应该指导信息搜集的思维方式**

**引导应用**："如果让你现在(在还没有查完所有资料之前)就对你的研究主题说点什么——你会说什么？这不是你最终的结论——只是你当前正在试图回答的问题。" — 这直接引导研究者进入角色3的思维方式。

#### 研究者的读者意识（来自 Preface "读者也是角色"的洞见）

Preface 的一个关键哲学：**读者的角色和你的角色是同时演进的**。你不能期待一个"知识推进者"式的研究报告被以"想知道有趣的事"的方式阅读。

- 如果写作者以角色3（知识推进者）写——但读者以角色1（取悦我）读 → 读者觉得太硬太枯燥
- 如果写作者以角色1（信息提供者）写——但读者以角色3（深入理解）读 → 读者觉得太浅太不严谨

**引导应用**："当你写作的时候——不只是在你提交时，而是在你形成论证时——你想象的读者是谁？你希望他们用哪种角色阅读你的研究？如果你的写作行为没有反映你预期的读者角色——调整你的论证，不要只调整语气。"

### 1.2 创造性的本质：找到你的切入点

本书的核心创造性框架来自 **§4.3 "Reading for a Problem"**。创造性不是凭空产生的，而是通过与现有研究的**积极对话**产生的。有两种基本路径：

**创造性同意（Creative Agreement）**：
> "你说的对，但还可以更进一步。"

| 策略 | 实质 | 引导问题 |
|------|------|---------|
| **补充支持** | 用更强/更新的证据支持已有论断 | "这个论断现有的证据够吗？你能提供什么新证据？" |
| **确认未经支持的论断** | 证明前人只猜测/假设的命题 | "他们假设了什么？你能证明它吗？" |
| **将论断应用到更广范围** | 将论断应用到新情境 | "这个规律只适用于 A 领域吗？在 B 领域是否也成立？" |

**创造性异议（Creative Disagreement）**：
> "你说的不完全对，我看到了不同的东西。"

| 策略 | 实质 | 引导问题 |
|------|------|---------|
| **分类/定义之争** | 它不是你以为的那种东西 | "你同意它的分类吗？有没有更好的框架？" |
| **整体-部分之争** | 你搞错了组成部分的关系 | "部分之间的关系真的是这样吗？有没有遗漏的关键部分？" |
| **因果之争** | 因果关系没那么简单 | "这是真正的因果关系，还是仅仅是相关？" |
| **历史/发展之争** | 它的起源/演变不是这样 | "它真的是从那里来的吗？发展路径是否被误述了？" |
| **视角之争** | 换个角度，看到不同真相 | "从另一个视角（社会/政治/性别/伦理...）看这件事会怎样？" |

**底线**：你不需要从零开始创新。你只需要在这个对话里找到一个别人还没占的位置。

### 1.3 好的问题 > 好的答案

来自 §1.2–1.3 和 §5.1 的核心洞见：研究的意义不在于给出最终答案，而在于**提出值得回答的问题**。

> "经验丰富的研究者梦想找到要解决的新问题。更大的梦想是解决一个甚至没人知道自己有的问题。"（§2.5）

### 1.4 写作即发现

来自 §10.4——一个经常被忽视的创造性来源：**写作本身是一种发现行为**。

> "正是在打草稿时，我们常常体验到研究中最激动人心的时刻之一：我们发现了那些直到将其表达出来才拥有的想法。"

这意味着：
- 不要等到"想清楚"再写——写的过程帮助你想清楚
- 当你"以新方式排列和重组研究结果"时，你会"发现新的含义、联系和复杂性"（§10 序言）
- "所有研究者都能回忆起这样的时刻：为了满足读者的期待而写作时，他们发现了思考中的缺陷，或发现了单为自己写作时会错过的洞察"（§10 序言）
- 最有价值的想法往往出现在初稿的最后几页（§2.4.3）

> "最有刺激性的研究常常不是给现有问题提供答案，而是提出我们尚未想到要问的新问题。"（§9）

因此，skill 的首要目标不是帮研究者"做完"研究，而是帮他们：
- **发现什么值得问**
- **理解为什么这个问题对学术共同体有意义**
- **找到自己能做出的独特贡献**

### 1.5 拥抱混乱

来自 §18.3 的警示：研究不是线性过程。它"更像在乱石嶙峋的山坡上气喘吁吁地上下攀爬，穿越杂草丛生的树林，有时在雾中，寻找你直到看见才认识的东西"。

因此 skill **不设严格的阶段边界**，不设对话轮次上限，允许：
- 研究者随时回到之前的讨论深化
- 重新审视和修正已经讨论过的问题
- 在对话中改变方向
- 在任何一个维度上停留任意长时间

#### 给好奇心创造条件（§18.2）

研究者的好奇心不是自发的——它需要被**激活和支持**。以下是有效研究作业/引导的核心特征，引导者可以将其融入对话：

1. **超越"交作业"的结果导向**。最好的研究问题来自研究者真正想知道的东西，由研究者将个人兴趣转化为公共意义。
2. **帮助研究者想象真正的受众**。"如果你的同学/同行/某个领域的专家需要知道你的发现——他们为什么需要？"
3. **提供丰富的上下文信息**。研究者不能在对对话一无所知的情况下就期望产出创造性贡献。先帮助他们理解所处的研究语境。
4. **建立中间反馈机制**。不要让研究者在真空中工作到最终提交。安排阶段性的分享和讨论。
5. **给予时间和缓冲**。研究需要"假开始、死胡同和修改重来"。设定中间截止日期和检查点，但不做僵硬的线性规划。
6. **通过设计鼓励诚实的研究实践**。当研究者找到工作的真实意义时，作弊的诱惑自然下降。

**引导应用**：如果研究者在某个维度卡住，回到这些条件——是否存在线索不足、受众不明确、或反馈缺失的问题？

### 1.6 形式是创造力的前提

来自 §18.1——最容易被误解的洞见：**形式不是创造力的敌人，而是它的条件**。

> "强调形式特征是有风险的。很容易将形式结构降格为空洞的训练。但如果学生被展示如何以正确的精神进行研究，论证的形式特征就会成为那些能激发和回报艰苦思考的问题的答案。这种认识是创造性和原创性研究的先决条件。"

**关键区分**：空洞的形式（脚注/参考文献的教条）vs "正确的精神"（把形式特征当作思考的工具）。Skill 始终以后者为前提。

### 1.7 语言选择与双语双区结构

Skill 采用**双语双区结构**，在顶层通过 `question` 工具让用户选择语言：

```
question(questions=[{
  "header": "Language / 语言",
  "question": "请问您希望用中文还是英文交流？/ Would you like to communicate in Chinese or English?",
  "options": [
    {"label": "中文", "description": "使用中文进行对话"},
    {"label": "English", "description": "Converse in English"}
  ]
}])
```

- 用户选择**中文** → 进入 `[ZH] 中文版本` 区
- 用户选择**English** → 进入 `[EN] English Version` 区
- 默认：中文

每个语言区是**独立完整的引导体验**，包含各自的 Triggers、核心理念、六大维度、引导策略、产出和成功标准。内容结构相同，语言不同：
- `[ZH]` 区：中文为主，关键术语辅助英文
- `[EN]` 区：全英文

**实现约束**：Language Selection 块必须在文件最顶部（YAML 之后），使用 `question` 工具呈现为可点击选项（非文本输入）。用户选择后，agent 只读取对应语言区的指令。

## 2. 引导维度

不再设计为"x 个严格按顺序的阶段"，而是**六个可自由切换的对话维度**。在每个维度中，skill 引导研究者深入探索；研究者随时可以跳转到其他维度或回到之前维度。

```
                        ┌──────────────────┐
                        │  进入学术对话     │
                        │  (你是谁？对话    │
                        │   在哪里进行？)   │
                        └────────┬─────────┘
                                 │
          ┌──────────────────────┼──────────────────────┐
          ▼                      ▼                      ▼
   ┌──────────────┐    ┌──────────────────┐    ┌────────────────┐
   │ 创造性切入点  │    │ 把论证搭起来        │    │ 研究的伦理与    │
   │ (同意/异议   │◄──►│ (claim-reason-   │◄──►│ 社会责任       │
   │  与扩展)     │    │  evidence-warrant)│    │ (对谁重要？    │
   └──────────────┘    └──────────────────┘    │ 谁受影响？)    │
          │                                      └────────────────┘
          ▼
   ┌──────────────┐
    │ 持续往前走    │
    │ (新问题 >    │
    │  最终答案)   │
   └──────────────┘
```

### 维度一：进入学术对话

#### 核心问题

你在和谁对话？他们在讨论什么？

#### 引导问题组
- "你对什么感到好奇？最近有什么让你困惑或惊讶的事？"
- "这个领域里，人们目前最关心的问题是什么？有什么悬而未决的争论？"
- "这个对话的主要参与者是谁？他们的核心主张是什么？"
- "你读到的文献中，有哪些分歧、矛盾或不完整的解释？"
- "如果让你用一个句子说清楚你的项目——'我研究 X，因为我想弄明白 Y，从而帮助大家更好地理解 Z'——那会是什么？"（§1.3 三句式）

#### 阅读方法引导（来自 §4.2）

研究者的阅读方式直接影响创造性产出。§4.2-4.5 给出了一套从宽厚到批判的渐进方法：

**两遍阅读法**
- **第一遍：宽厚地读**。不要找茬，先帮来源把道理说通。否则你容易被它与你竞争的部分引向偏见。
- **第二遍：批判地读**。思考"我会怎么回应？"——如果你不能用自己的话重述一个段落，你还没有充分理解它来提出异议。
- "整个与来源互动的目的是推进你自己的思考"——不是积累数据，而是寻找"激发你自己思考的问题、问题和论证"。

**从"找问题"到"找论证"（§4.4 阅读以识别论证）**
- 不仅要问"这篇来源在说什么"，还要问"它是如何建立它的论证的？"
- 研究者可以在文献中识别出论证的五个要素（§5）：主张、理由、证据、warrant、回应
- 引导问题："这篇来源试图证明什么？它用什么理由来支持？那些理由有证据吗？它预先回应了什么反对意见？"
- 如果能识别他人论证的结构，研究者就能更清楚地定位自己的论证（同意/延伸/挑战）

**阅读以收集数据和支撑（§4.5）**
- 不同类型的问题需要不同类型的证据，研究者需要学会识别哪些类型在自己的领域被视为证据
- 引导问题："这篇的来源用什么来支撑它的理由？是数据、引用、逻辑推理还是权威论据？"
- 关键提醒：不要只收集"支持你自己论点"的引文——也要收集那些"挑战你论点"的证据，因为回应它们会让你的论证更强

#### 提示

研究者说不清第三个部分（"从而..."）是完全正常的。这本书明确说：很多高级研究者也是在完成初稿后才能说清。Skill 的任务是帮助研究者**开始朝向**这个答案，而不是要求开始时就有。

#### "我不在乎"检查点

在初步讨论后，向研究者抛出这个问题——"如果你在会议上说出你的研究问题，台下的人会回应'我不在乎'吗？为什么？" 这是全书最重要的自我检验。

#### 引导式引言结构：Context → Problem → Response（来自 §14.1–14.4）

即使研究者有了清晰的问题和切入点，如何向读者呈现也是一个关键的 craft 问题。§14 的引言结构是全书最实用的写作框架——但它首先是一个**思考框架**：帮你理解自己的研究在对话中的位置。

```
┌─ 1. Context（共同基础）────────────────────────────────────────┐
│   "关于 X，我们已知……"                                         │
│   → 建立共识，让读者点头："嗯，这我同意，我们在谈同一件事。"      │
└────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─ 2. Problem（问题空间）────────────────────────────────────────┐
│  2a. "但是我们还不知道 Y……"（缺口）                             │
│  2b. "不知道 Y 的后果是……"（代价）                               │
│  → 制造张力："等等，这确实是个问题！"                            │
└────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─ 3. Response（你的贡献）───────────────────────────────────────┐
│   "所以我做了/发现了/论证了 Z……"                               │
│   → 释放张力："哦，原来如此，这就是为什么这个研究重要。"         │
└────────────────────────────────────────────────────────┘
```

#### 引导方式

**不要把结构作为"规则"强加，而是作为思考工具**：

- "如果你有 30 秒向同行解释你的研究——你先说什么来建立共识？" → Context
- "然后你指出什么目前还不知道或不确定？为什么会让人在意？" → Problem (2a + 2b)
- "然后你说那你自己做了什么？" → Response

#### 为什么这对创造性研究重要

很多研究者在"制造张力"这一步失败了——要么没有清晰的缺口（2a），要么没有说清不知道这个缺口的代价（2b）。§14.4 明确指出：**缺乏 2a 的研究没人读，缺乏 2b 的研究没人关心。**

#### 辅助提示（来自 §14.6）
- 引言通常是研究最后一个写的，但应该是读者第一个读的
- "不要试图在引言中总结所有的发现。引言的唯一工作是让读者理解你研究的问题——以及为什么他们应该在乎。"
- 如果研究者在步骤 2b（不知道的后果）卡住，回到维度二的 "So What?" 级联

#### 引言节奏控制（来自 §14.5 Setting the Right Pace）

引言的长度和节奏取决于读者。§14.5 提醒：读者的注意力是有限的。

- **对熟悉该领域的读者**：快速进入 Problem，甚至可以直接从缺口开始——过多的背景信息会让专家不耐烦
- **对不熟悉的读者**：花更多时间建立 Context，放慢节奏逐步导出问题
- **关键原则**：引言应该以你能**维持读者注意力**的最短长度完成三个步骤（C→P→R）。不要为了"完备"而赘言
- **诊断工具**："如果读者只读你的前三段和最后两段，他们能理解你研究的问题和你找到的答案吗？"

**引导应用**：如果研究者说"我的引言写了五页还觉得没说清楚"——提示他们先判断目标读者了解多少，再按需裁剪。

#### 引导式结论结构：重申 → 意义 → 指向未来（来自 §14.7）

如果引言是"制造张力"→"释放张力"的弧线，结论就是"再次打开张力"→"指向更远前景"的弧线。§14.7 给出三步骤：

```
┌─ 1. 重申核心主张 ──────────────────────────────────────────────┐
│   不简单重复，而是用更广的措辞回溯："所以，我们发现了 Z。"        │
│   → 让读者离开时清楚记得你的核心贡献是什么                       │
└────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─ 2. 添加新的意义或应用 ──────────────────────────────────────────┐
│   把研究往前推一步："这个发现不仅回答了最初的问题，还意味着……"    │
│   → 让读者感到你的研究有超出最初问题范围的含义                    │
└────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─ 3. 指向未来 ──────────────────────────────────────────────────┐
│   指出什么还没有解决："这开启了什么新问题？"                     │
│   → 让读者看到你的研究是持续对话的一部分，而不是终点             │
└────────────────────────────────────────────────────────┘
```

**引导方式**：
- "如果读者只记住你文章的一句话——你希望是哪一句？" → 提炼核心主张
- "知道了你的发现之后，我们现在能理解什么以前无法理解的东西？" → 添加新意义
- "你的研究最有趣的一个未解决问题是什么——不是你这次能回答的？" → 指向未来

**与 §3.4 自检引擎的关系**：步骤 3（指向未来）直接对接创新性自检引擎的 Step 5（研究后果）。如果研究者在 Step 5 卡住，回到这里的维度五深化。

### 维度二：找到你自己的切入点

#### 核心问题

你能贡献什么别人没有的东西？

这是 skill 的核心维度。使用 §4.3 的框架引导研究者扫描可能的切入点：

#### 引导策略

##### 1. 扫描现有文献中的位置
- "在你读过的研究中，哪些结论你认同但觉得还不够？还能怎么推进？" → 寻找**创造性同意**的机会
- "哪些结论你不同意？你觉得他们的分析忽略了什么？" → 寻找**创造性异议**的机会
- "有没有哪些你觉得重要的东西，似乎没人讨论？" → 寻找**创造性综合**

##### 2. 使用 "So What?" 级联测试切入点

对每个可能的切入点，逐层追问：
```
"如果你回答了这个问题..."
  → "所以呢？"
    → "但如果他们知道了这个..."
      → "所以呢？"
        → "这改变了什么？"
          → "所以呢？"（直到自然停止）
```

判断标准：研究者能自然回答"所以呢？"而不卡壳时，切入点已足够具体。

##### 3. 检验问题的价值（来自 §2.4）

对候选问题逐一检验：
- "你能回答这个问题吗？（资源/时间/能力范围内）"
- "除了你自己，还有谁在意这个问题？"
- "这真的是一个问题（有未知需要探索），还是只是你好奇（已有明确答案）？"
- "如果这个问题被回答了，会改变什么？"

### 附加：寻找与评估来源（来自 Ch 3  Finding and Evaluating Sources）

找到好问题之后，研究者需要**找到好来源**来支撑探索。这一实践层面虽然更多是技巧而非创造性思维，但直接影响了后续论证的质量。

#### 三大类来源及其用途

| 类型 | 用途 | 典型例子 | 在论证中的角色 |
|------|------|---------|-------------|
| **一手来源**（Primary） | 提供"原始数据"——研究者将以其为证据 | 档案、信件、访谈、田野笔记、实验数据 | 核心证据 |
| **二手来源**（Secondary） | 学习领域内其他研究者的工作、参与对话 | 同行评议期刊论文、学术专著 | 定位问题、寻找分歧、获得模型 |
| **三手来源**（Tertiary） | 快速了解新领域概貌 | 百科全书、教科书、Wikipedia | 初步了解，不作为学术依据 |

**关键洞察**：来源的分类是**相对而非绝对**的，取决于你的研究问题。一篇学术论文通常是二手来源，但如果你在研究那位作者本人，它就变成了一手来源。

**引导应用**："你在这个项目里用什么作为一手来源（你的原始证据）？用什么作为二手来源（你与谁的对话）？如果你只有二手和三手来源——你需要找到一手来源才能做出有原创性的论证。"

#### 评估来源的四项标准（来自 §3.4）

| 标准 | 引导问题 |
|------|---------|
| **相关性** | 这本书/文章是否直接回应你的研究问题？快速用索引/摘要判断 |
| **可靠性** | 来源是否经过同行评议？出版机构有无信誉？作者是否为领域内公认研究者？ |
| **时效性** | 领域内什么算"最新"？计算机科学几个月、社科十年、人文学科可以更久 |
| **公正性** | 来源是否愿意考虑其他观点？有无明显的偏见或利益冲突？ |

#### 超越可预测来源（§3.5）

最有趣的研究往往来自跨界——在标准来源之外，引入非同寻常的材料。"如果你在做农业变化的经济影响，不妨看看同时代的戏剧中乡村人物如何被描绘；如果你在关注视觉表征，也不妨同时做做经济史研究。"

**引导应用**："除了这个领域人人都读的标准文献——还有什么来源（不同领域、不同媒介、不同时代的）可能给你的论证带来新鲜的角度？"

#### 利用人来推进研究（§3.6）

- **图书馆员**是研究过程中最被低估的资源——他们不仅帮你找书，还能帮你精炼搜索词、发现遗漏
- **专家**（哪怕是邮件往来）可以告诉你领域内的开放问题、对你的初步论点提出反馈、推荐阅读
- **注意事项**：用人的时候要遵守伦理（Ch 17）

**AI 时代的研究来源**（§3 Quick Tip 关于生成式AI）：生成式AI可以——①帮助你探索新方向 ②生成初步信息 ③推荐来源 甚至创建初稿草稿。但必须：诚实地标注AI的使用、批判性地验证AI输出的准确性、透明地告知受众你的使用方式。

### 维度三：把论证搭起来

#### 核心问题

你的论点站得住吗？你拿什么说服读者？

使用 §§5–8 的框架引导研究者逐步建构论证：

#### 1. 核心论证骨架

引导研究者自然回答（避免使用术语）：
```
"你希望读者最终相信什么？"                   → Claim
"你凭什么这么说？"                           → Reasons
"每个理由背后，你用什么东西来支持？"            → Evidence
"为什么你觉得这个理由能支撑这个结论？"          → Warrant
"如果有人拿不同的解释或反例来质疑，你怎么应对？" → Acknowledgment & Response
```

#### 1. 论证规划：在写之前想清楚逻辑（来自 §5.5 Planning Your Argument）

在进入具体的论证要素之前，研究者需要理解**论证的层级结构**。§5.5 给出了一个从核心主张出发的规划路径：

**第一步：从最核心的主张开始**
- 在引导中对研究者说："如果你只有一个句子来说服你的读者——那个句子是什么？"
- 这是你的**核心主张**（main claim），所有其他部分都是为了支持它

**第二步：问自己"我需要先让读者相信什么"**
- 核心主张通常不能一步到位的论证——它依赖多个**子论证**（sub-arguments）
- 引导问题："在你提出核心主张之前，读者需要先接受什么？"
- 每个子论证本身也是一个完整的 claim + reason(s) + evidence 结构

**第三步：规划论证的分层结构**
```
核心主张（Main Claim）
  ├── 子论证 1：理由 A + 证据 A → 支撑核心主张的某个方面
  │     ├── 可能还需要子-子论证来支撑理由 A
  │     └── 需要证据来支撑
  ├── 子论证 2：理由 B + 证据 B → 支撑核心主张的另一个方面
  ├── 子论证 3：回应一个主要反对意见
  └── 如果论证被接受→指向的意义（结论部分）
```

**第四步：检查层级完整性**
- "你有核心主张吗？"
- "每个理由都有对应的证据，还是某些理由只是另一个推理链条的中间站？"
- "有没有读者会提出的问题你没有预先回答？"

**引导应用**：不要求研究者在纸上画出完整的论证层级图（对初学者来说太抽象），而是用口语化的方式逐步问：
- "你说服读者接受你的核心主张之前，他们需要先相信哪三件事？"
- "那三件事的每一件——你有什么证据支持它？"
- "如果有人不接受某一件——你怎么补充论证？"

#### 5. 研究者品格与可信度（来自 §5.6 Ethos）

论证的有效性不仅取决于逻辑结构，也取决于读者对研究者的**信任**。§5.6 区分了三种说服路径：

| 路径 | 定义 | 在学术写作中如何体现 |
|------|------|-------------------|
| **Logos（逻辑）** | 论证本身的说服力 | 理由+证据+推理的严密性 |
| **Pathos（情感）** | 唤起读者的情感共鸣 | 选择对方也在意的例子、显示研究问题的紧迫性 |
| **Ethos（品格）** | 研究者给人的印象 | 公平对待反方 → 可信；坦诚承认局限 → 可信；准确引用 → 可信 |

**Ethos 是可以通过论证设计来建立的**——研究者不需要"显得有品格"，而是通过透明的论证实践来赢得信任：

**建立 Ethos 的具体策略**：
1. **公平呈现反对观点**（§9.5-9.6的核心应用之一）
2. **主动承认证据的局限**（而不是等到被指出）
3. **准确引用和诚实呈现数据**
4. **措辞尊重（§5.6）**："批评观点而非人"；慎用贬义词
5. **显示你已经考虑了反例和替代解释**

**引导问题**：
- "如果让一个不同意你的人读你的论证——他们会觉得你公平地对待了他们的观点吗？"
- "你有没有主动承认你的某个证据的局限？还是你只呈现了对你自己有利的一面？"
- "你的措辞让人感觉你在邀请对话，还是宣告胜利？"

**关键洞察**：Ethos 不是"加分项"。缺少 Ethos 的论证——即使逻辑上正确——也可能不被接受，因为读者无法信任做出论证的人。

#### 1a. 理由与证据的区别（来自 §7.1–7.2）

研究者最常混淆的就是"理由"和"证据"。两者角色完全不同：

> **理由**（Reason）回答"为什么你应该相信我的主张"——是推理链条上的中间站，是**逻辑断言**。
> **证据**（Evidence）回答"你怎么知道这是真的"——是支持每个理由的**具体事实/数据/观察**。

| 混淆类型 | 表现 | 引导纠正 |
|---------|------|---------|
| **把理由当证据** | "因为 A 导致了 B"（这是一个理由，但读者会追问：你怎么知道 A 导致了 B？） | "你凭什么说 A 导致了 B？你观察到了/读到了/看到了什么具体东西？" |
| **把证据当理由** | "我观察到 X% 的人做了 Y"（这是证据，但读者会追问：所以呢？这支撑了你的什么观点？） | "这个观察支持了你的什么主张？它为什么有助于说服读者？" |
| **只有理由没有证据** | "我认为……因为逻辑上应该是这样……" | "这听起来很合理。但你的读者可能会问：你有什么具体依据？是数据、观察、还是哪篇文献的结果？" |
| **有证据但没有推理链条** | 列了一堆事实/数据 | "这些数据在一起说明了什么？你先有了什么主张，再用这些数据来支持？" |

**实用判断标准**：如果你在一个论证环节的"因为"后面放的不是引用/数据点/具体观察，而是一个以"所以"或"因此"开头的逻辑断言——那里缺了证据。

##### 证据评估的五项标准（来自 §7.5）

区分了理由和证据只是第一步——研究者还需要**判断证据的好坏**。§7.5 给出了五项通用的检验标准：

| 标准 | 引导问题 | 常见问题 |
|------|---------|---------|
| **准确**（Accuracy） | "你的数据/引用和原始来源核对过吗？别人重复你的测量会得到相同结果吗？" | 转述错误、数据抄写失误 |
| **精确**（Precision） | "你是用模糊词（'很多'、'大多数'、'显著'）还是具体数字描述的？你的精确度适合这个领域的要求吗？" | "a great deal" vs "47.3%" |
| **充分且有代表性**（Sufficiency & Representativeness） | "你的证据够说服一个合理的怀疑者吗？你选取的样本是否能代表整体？有没有 cherry-picking？" | 一个孤例当普遍规律，选择性呈现有利数据 |
| **权威**（Authority） | "你的来源可信吗？经过了同行评议吗？在领域内被认可吗？" | 引用维基百科而非一手来源，或来源已过时 |
| **清晰**（Clarity & Understandability） | "你的读者能立刻理解这个证据如何支持你的论证吗？需要解释吗？" | 引用的段落没有解读、图表没有说明 |

**关键提醒**：即使证据在某一项上有瑕疵，有时也可以使用——只要你**主动承认其局限性**。"如果你指出那些似乎支持你主张的证据并因为不可靠而拒绝它，你展示了自己谨慎、自我批评，因此是值得信赖的。"（§7.5.1）

##### 证据类型：你的论证需要什么种类的支持？（来自 §7.3 Types of Evidence）

并非所有证据都是同一类。§7.3 区分了几种主要的证据类型，研究者需要根据不同研究问题选择适合的类型：

| 证据类型 | 定义 | 适用场景 | 举例 |
|---------|------|---------|------|
| **事实/统计数据** | 可验证的具体数据点 | 实证研究、因果论证、量化学科 | "2023 年全球碳排放量同比增长 1.1%" |
| **例子/案例** | 单次具体事件或案例 | 演示普遍规律、让抽象变具体 | "例如，在田纳西州的一个学区中……" |
| **权威引用** | 引用被认可的专家观点 | 补充性支撑、建立共同基础 | "正如 Schmidt (2022) 论证的……" |
| **文本证据** | 从文本中引用的段落 | 人文学科、文学/历史研究 | "在《红楼梦》第七十四回中，作者写道……" |
| **逻辑推理** | 基于前提的推理链 | 纯理论论证、数学/哲学论证 | "如果 A 成立，且 B 成立，则 C 必然成立" |

**关键原则**：不同类型的证据有不同说服力。单一类型往往不足以建立复杂论证。最强论证通常使用**多种类型相互补充**。

**引导问题**：
- "你的主张需要什么类型的支持——数据、例子、引用还是逻辑推理？"
- "你是否只依赖了一种证据类型？引入另一种类型会让论证更稳固吗？"
- "在你的领域，什么样的证据被认为是最有力的？"

##### 证据 vs 证据报告（来自 §7.4 Evidence v. Reports of Evidence）

§7.4 做出了一个精细但重要的区分：研究者手中往往是"证据报告"而非"证据本身"：

> **证据本身**（Evidence Itself）是原始数据/观察。
> **证据报告**（Report of Evidence）是作者对证据的复述、总结或转引。

**为什么这重要**：
- 当你引用他人的文献时，你通常不是在引用"证据"，而是在引用该作者**对证据的报告**
- 原作者的偏见、选择性呈现、转述错误都可能影响你获得的信息
- 层级越多（A 引用了 B 转述了 C 的结果），失真风险越大

**引导应用**：
- "你引用的这段数据——是你从原始来源核对的，还是从另一篇论文中转引的？"
- "如果可以的话，尽量追溯到一手来源或者最接近一手来源的版本。"
- "如果你必须转引别人的数据，请注明'转引自 X 引用了 Y 的数据'——这在学术上是诚实的行为。"

**与§3的关系**：这就是为什么 Ch 3 强调查找一手来源的重要性——二手报告总可能有偏差。

##### 从论证规划到具体证据：证据在论证层级中的位置（来自 §5.5+§7 的整合）

将论证层级规划（§1，来自 §5.5）与证据选择（§7）结合起来：

```
核心主张 (需要方向性证据：支持整个项目的可行性和意义的宏观数据)
  ├── 子论证 1：理由 A + 证据 A1, A2 (每个理由可能需要多种证据)
  ├── 子论证 2：理由 B + 证据 B1, B2 (不同类型证据相互补充)
  ├── 子论证 3：回应反对 → 证据 C (回应对手观点也需要证据)
  └── 结论：意义陈述 (需要定位性证据：说明研究在更广对话中的位置)
```

**引导应用**：
- 与其一次性地问"你的证据是什么"，不如逐层追问："你的核心主张需要什么宏观证据来支撑？你的每个子论证的具体证据是什么？你回应反对意见时用什么来支撑？"

#### 1b. 从理由到主张的桥梁：Warrant（论证担保）（来自 §8.1–8.3）

Warrant 是连接理由与主张的**一般性原则**——它回答"为什么这个理由能支撑那个主张？"

```mermaid
graph LR
    A[理由<br/>"该疗法在试验中<br/>使肿瘤缩小30%"] --> C{需要 warrant<br/>桥接}
    B[主张<br/>"该疗法应成为<br/>一线治疗方案"] --> C
    C --> D[Warrant<br/>"如果一种疗法在 RCT 中<br/>使肿瘤显著缩小，<br/>它就应该成为一线方案"]
```

##### 关键要点

- Warrant 通常是**隐含的**——作者和读者共享的默认假设不需要写出来
- 但当 warrant 本身可能被质疑时，**必须显式阐明和辩护**
- 最难的研究往往是**warrant 层面的创新**——不是发现了新证据，而是挑战了"什么样的证据算数"这个前提
- 判断标准：如果你觉得"这个理由自然就能推出这个主张"——检查一下你是否默认了一个读者可能不接受的 warrant

##### 引导问题集（按难度递进）
- "为什么你觉得这个理由就能支撑你的结论？你默认了什么假设？"（基础）
- "你的读者可能不认同这个假设吗？如果他们用不同的前提读你的论证呢？"（对抗性阅读）
- "如果只保留你最核心的一条论证链——它的 weakest link 是证据、推理还是这个不言自明的假设？"（薄弱环节诊断）
- "你研究中最根本的'如果……那么……'结构是什么？这个结构本身有没有可能被挑战？"（warrant 层面的创新）

##### 与"类型的质疑"的关系

Warrant 质疑通常是三类质疑中最深刻的一种——因为它挑战的不是某个具体证据或推理，而是整个论证框架赖以建立的前提。

##### 高阶：何时必须显式阐明 Warrant（来自 §8.4 When to State Your Warrant）

§8.4 给出了四条实用判断标准——当以下任一情况出现时，warrant 必须显式写出：

| 条件 | 判断问题 | 例子 |
|------|---------|------|
| ① **读者可能不共享你的 warrant** | "你的读者默认接受这个假设吗？还是你的假设是反直觉或小众的？" | 用进步主义的逻辑去论证传统价值观——两边不共享同一个前提 |
| ② **论证涉及多个复杂步骤** | "每个步骤的推理假设都一样吗？还是不同步骤依赖于不同前提？" | "A 导致 B，B 类似于 C，所以 A 也影响 C"——每一步的 warrant 都不同 |
| ③ **你的 warrant 可以被挑战** | "有人会质疑你假设的合法性吗？" | 你假设"市场经济总是最有效的资源配置方式"——但有人不同意 |
| ④ **你的论证依靠非主流 warrant** | "你用什么原则来支持这个推理——这个原则在你的领域是主流还是边缘？" | 你用精神分析框架去解释经济行为——需要为这个框架的时间性辩护 |

**引导问题**："仔细看你论证中最关键的那步推理。你觉得读者会不假思索地接受它吗？如果不是——把它写出来。"

##### 高阶：用"如果…那么…"测试你自己的论证（来自 §8.5 Testing Your Argument）

§8.5 是一位资深研究者自我检查 warrant 的简洁方法——把你的论证转化为"如果……那么……"结构来暴露隐含假设：

**方法**：对论证中的每一步关键推理，写出它的"如果-那么"形式：

> "如果你接受我的理由（证据/数据）……那么你是否必须接受我的主张？"

如果答案是**"不一定"**——说明缺少了某个明确或隐含的额外假设。那个缺失的假设就是你需要检查的 warrant。

**逐层诊断**（由浅到深）：
1. **事实层面**："如果你接受我的数据 X……那么你是否接受我的描述 Y？" → 需要定义性 warrant
2. **因果层面**："如果你观察到 A 与 B 相关……那么你是否接受 A 导致了 B？" → 需要因果性 warrant
3. **价值层面**："如果你同意我的标准……那么你是否接受我的评价？" → 需要评估性 warrant
4. **行动层面**："如果你接受我的评估……那么你是否同意应该采取行动 Y？" → 需要实践性 warrant

**引导应用**："我们来找你论证中最核心的一个'如果…那么…'。你能写出来吗？如果你卡住了，这往往意味着你的推理中有隐藏的假设。"

##### 高阶：挑战他人论证中的 Warrant（来自 §8.6 Challenging Others' Warrant）

§8.6 提供了一种阅读和回应文献的方法——不仅仅是质疑他人的证据或推理，而是挑战他们**隐含的假设**:

**这是最有攻击力但也最需要谨慎的策略**：如果你能指出对方的论证依赖于一个他们自己都不一定意识到的假设——而这个假设可能是错的——你在 warrant 层面就发动了最深刻的对话。

**三层挑战策略**（按力度递进）：
1. **指出问题**："为了从你的理由达到你的主张，你似乎假设了______。这是有争议的，因为______。"
2. **提供替代**："即使你假设了______，如果换成______假设，你的论证还能成立吗？"
3. **重铸对话**："你的论证依赖的并不是你的证据本身，而是你对______前提的预设。如果这个前提不成立——你的整个论证需要重构。"

**伦理边界**（§8.6 明确警告）：挑战他人的 warrant 时，必须确保你没有曲解对方。先用自己的话重述对方的论证，让对方确认理解了再开始挑战。

**引导应用**："你在文献中读到的最让你不服气的一个论证在哪里？不是因为它数据错了，而是因为你感觉作者依赖了一个你可能不接受的假设。"

#### 1c. 三种需要预判的质疑类型（来自 §9.1–9.3）

引导研究者系统性地预判三类问题：

| 质疑类型 | 挑战什么 | 引导问题 |
|---------|---------|---------|
| **关于研究问题** | 我为什么要关心？这个问题真的重要吗？ | "你会怎么回应一个说'这问题谁在乎'的人？" |
| **关于论证可靠性** | 你的主张有争议吗？证据够吗？可信吗？ | "如果你的证据被质疑来源，你怎么辩护？" |
| **关于替代解释** | 有没有其他解读方式？你遗漏了什么？ | "如果有人拿另一种框架来解释同样的事，你怎么回应？" |

##### 黄金中道原则（§9.4）

回应太多质疑会冲淡核心，回应太少会显得轻率甚至无知。优先回应：①领域内的重要替代观点 ②受众可能希望成立的观点 ③已知的重要反例 ④你最没有把握的推理环节。

##### 如何组织回应：把反论证转化为子论证（来自 §9.5–9.6）

预判了质疑之后，研究者需要**组织回应**。§9.5–9.6 提供了把"防守"转化为"建设性对话"的策略：

**核心方法**：不把回应当作"对抗攻击"，而是把它呈现为一个**子论证**（sub-argument）：

```
格式模板：
 "有些批评者可能会认为 [反对观点]。然而，[你的回应]，因为 [你的理由]。
  尽管如此，我们承认 [你愿意让步的地方]。但这并不改变 [核心主张仍然成立]，因为……"
```

**三种回应策略**（按力度递进）：

| 策略 | 句式 | 适用场景 |
|------|------|---------|
| **让步+限定** | "虽然……但……" | 反对观点部分成立，但影响有限 |
| **拒绝** | "尽管这个反对意见看上去合理，但它在这一点上不成立，因为……" | 反对观点基于错误证据或推理 |
| **反转** | "这个反对意见不仅没有削弱我的论证，反而加强了它，因为它揭示了……" | 反对观点可以转化为正面证据 |

**关键提醒**（来自 §9.6）：
- 回应的措辞本身就传达了你的态度——是真诚考虑还是轻蔑否决
- "虽然……但……"是最安全的结构：承认对方的价值再提出你的不同看法
- 绝不要用"你错了"或"你的观点站不住脚"——这会关闭对话
- §9.6 提供了几十个措辞示例（"尽管如此……在这个程度上，我们同意……然而……"），引导研究者注意回应的语气

#### 2. 论证压力测试（来自 §9）

在研究者形成初步论证后，引导他们自我质疑：
- "你的论证最薄弱的环节在哪里？"
- "如果你不同意自己的论点，你会怎么反驳？"
- "同行最可能质疑你哪一步推理？"
- "你的证据是否足够？是否有反例你还没处理？"

#### 3. 论证不是为了赢

来自 §5.1 的关键提醒：研究论证的"目标不是一方强迫另一方同意，而是让各方在理解与知识上共同成长"。引导研究者的论证姿态是**邀请对话**而非**宣告胜利**。

#### 3a. 让主张自带意义的实用技巧："尽管/虽然"结构（来自 §6.2.2）

用"尽管/虽然"开头写主张，天然展示它挑战了什么：

> **不这样**：*远程工作对社会有害。*
> **这样**：*尽管远程工作为公司及其员工提供了许多好处，但它也威胁到城市中心的社会结构，因为……*

这迫使研究者同时回答"我知道你相信什么"和"但我看到了不同的东西"——在 claim 层面就开启了对话，而不是等到结论才揭示。

#### 3b. 让主张从模糊到具体（来自 §6.1）

主张的模糊程度直接决定了论证能走多远。以下策略帮助研究者将模糊感觉打磨成能引导具体论证的主张：

| 阶段 | 引导问题 | 演化示例 |
|------|---------|---------|
| **初始感觉** | "你直觉上想说什么？别管对不对，先说。" | *远程工作对城市不太好。* |
| **识别关键词** | "你这句话里哪些词需要定义？（'不太好'指什么？'城市'指哪部分？）" | → *远程工作威胁了市中心的社会结构。* |
| **系词检查** | "你的主张使用的是什么关系？（是/不是/导致/阻止/改变……？这个关系准确吗？）" | → *远程工作改变了市中心的人员流动模式。* |
| **范围校准** | "这个主张对谁/什么时候/在什么条件下成立？" | → *混合办公模式减少了市中心商业区的客流量。* |
| **对话定位** | "你的主张挑战/延伸/修正了什么既有理解？" | → *尽管混合办公提供了灵活性，但它使市中心商业区面临结构性客流下降。* |

##### 主张类型与问题类型的匹配（来自 §6.1）

除了让主张从模糊变具体，研究者还需要确保**主张的类型匹配问题的类型**。不同类型的问题需要不同类型的论证：

| 问题类型 | 对应主张类型 | 你需要证明什么 | 示例 |
|---------|------------|--------------|------|
| **存在性问题** | 事实/定义主张 | 某事物是否存在、或应如何归类 | "这种新型病毒不属于已知的 A 家族病毒。" |
| **因果问题** | 因果主张 | A 导致了 B（不是仅仅相关） | "臭氧层损耗是导致南极磷虾种群下降的主因。" |
| **评价性问题** | 评估主张 | 某事物是好/坏/有效/更优——基于什么标准 | "基于五年随访数据，方案 B 在成本效益上优于方案 A。" |
| **行动性问题** | 实践主张 | 应该做什么——需要可行性和代价论证 | "因此，监管机构应采用方案 B 作为新标准。" |

**为什么这重要**：研究者经常提出一个很好的概念性问题（"我好奇 X 是怎么运作的"），但在写主张时却不自觉地滑向实践主张（"我们应该做 Y"），导致论证不匹配。引导研究者检查：

> "你真正想回答的是'是什么'、'为什么'、'怎么评估'、还是'应该怎么做'？你的主张反映了同一个问题吗？"

如果研究者想提出实践主张（"应该怎么做"），需要额外论证：①解决方案可行；②成本低于问题代价；③不会制造更大的问题；④优于替代方案（§6.1）。

##### 关键提醒

这不是一次完成的线性过程。大多数研究者在研究全程会多次反复打磨主张。有时你需要先推进到证据和论证再回来细化主张——这是完全正常的。

##### "尽管/虽然"结构 vs 一般主张

两者各有用途。
- "尽管/虽然"结构最适合**呈现完整对话**（"我知道已有说法，但我提出一个不同的视角"）
- 一般主张更适合**研究中期整理思路**（"我现在相信什么？"）
- 引导者应根据研究者的阶段灵活选择：探索期用一般主张，呈现期用"尽管/虽然"结构

##### Qualifying Claims：限定主张的强度（来自 §6.3 Qualifying Claims）

§6.3 区分了两种类型的限定词——研究者需要根据证据的强度谨慎选择：

**类型 A：限定主张的肯定程度（Degree of Certainty）**

即使证据支持你的主张，也很少足以证明它是"绝对正确"的。精确的限定词反而增加了可信度：

| 肯定程度 | 措辞 | 引导问题 |
|---------|------|---------|
| **强主张** | "毫无疑问……" / "这证明……" | "你的证据真的支持这么强的措辞吗？还是说'强烈提示'可能更准确？" |
| **中等主张** | "这暗示……" / "这表明……" / "有理由相信……" | "如果你换一个更谨慎的措辞，你的论证会更有说服力还是更弱？" |
| **弱主张** | "这初步说明……" / "这引发了……的可能性" / "可能是……" | "你的证据强度允许你做什么程度的声明？" |

**核心提醒（§6.3）**："你认为你的证据证明了什么——以及你声称它证明了什么——两者通常是不同的。一个谨慎的研究者知道这个差别并且诚实面对它。"

**类型 B：限定主张的条件范围（Conditional Scope）**

不是所有主张在所有条件下都成立。明确限定条件保护你的论证免受"这不适用于 Y 场景"的攻击：

| 限定维度 | 引导问题 | 示例 |
|---------|---------|------|
| **时间** | "这个主张在什么时间范围内成立？" | "短期而言……长期则……" |
| **群体** | "这个主张适用于谁？" | "在发展中国家……" |
| **场景** | "这个主张在什么条件下成立？" | "当 A 和 B 同时存在时……" |
| **来源** | "这个主张来自什么视角？" | "从功利主义的角度看……" |

**与 §7.5 的关系**：限定词的强度应匹配证据的质量。五项标准（准确/精确/充分/权威/清晰）中任一项目若存在瑕疵，都应相应降低限定强度。

**引导应用**："你现有的证据允许你说到什么程度？如果你为了让人注意而过度声明——不被信任。如果你过于谨慎——没人注意。找到这个平衡点就是 craft。"

### 维度四：研究的伦理与社会责任

#### 核心问题

谁可能受你的研究影响？你有什么责任？

来自 §17 的伦理框架：

#### 1. 对自己的责任（个人诚信）
- 是否准确引用了来源？
- 是否有不能反驳的反对意见被隐瞒了？
- 是否有证据被选择性呈现？

#### 2. 对学术共同体的责任
- 你的研究是否推进了共同体的理解？
- 你是否公正地对待了与你观点不同的研究？
- 承认了他人贡献吗？

#### 3. 对社会的责任
- 你的研究问题本身是否有伦理考量？
- 谁可能被你研究影响？他们对知情权/参与权有何诉求？
- 你的研究是否可能被误用？是否存在权力差异需要关注？

### 维度五：持续往前走

#### 核心问题

这个研究打开了什么新问题？

来自 §9 和 §14.7 的关键洞见——好的研究不终结对话，而是开启新的对话方向。

#### 引导问题
- "如果你的研究发现被接受了，接下来什么新问题会浮现？"
- "你的研究会开启什么新的研究方向？"
- "还有什么你希望回答但这次无法解决的问题？"
- "这个项目可能衍生出什么子项目？"

### 维度六：把你的论证写出来、讲出来

为什么一个专注于"创造性研究思维"的 skill 需要关心写作和表达？因为 — §10 的核心理念 — **写作本身就是一种发现行为**。引导研究者理解如何交付论证，能帮助他们在写作中继续发现、在表达中澄清思考。

#### 1. 写作规划与常见障碍（来自 §10.1–10.3 Planning Your Writing）

写作不是研究的"最后一步"——它是研究的一部分。§10 区分了三种研究者在写作中常见的障碍模式：

| 障碍模式 | 表现 | 引导纠正 |
|---------|------|---------|
| **"还没准备好"型** | "我还没查完所有资料，还不能开始写" | "写初稿不是为了完成，而是为了发现你还不知道自己在想什么。"（§10.4） |
| **"完美初稿"型** | 试图每句话都写对再往下走 | "把初稿当作一个可以改的草稿——不是向读者的期末展示，而是你自己的思维草稿。" |
| **"结构瘫痪"型** | 不知道从何入手 | "从你最确定的那个部分开始写——不是你一定要从引言写起。" |

**引导应用**："你卡在哪个阶段？我们用 15 分钟写一个完全粗糙的'核心论证段落'——给自己一个起点，之后再改。"

#### 2. 论证的组织结构（来自 §11 Organizing Your Argument）

论证的组织不是"填充模板"，而是引导读者沿着你的思考路径前进。§11 提供了两种思考组织方式：

**读者视角的组织原则**（§11.2）：
- 读者需要在每一步都知道两件事：**"我们在谈什么"** 和 **"为什么在谈这个"**
- 每一段的起点应该是读者已知或已接受的——而不是一个新信息
- 新的信息应该放在段落的后半部分，在已知信息的"地基"上建立

**引导应用**："读你的每一个段落的第一句话。它们加在一起清晰地告诉读者你在讲什么了吗？如果第一句话就直接跳入新信息——加一句'定位句'来建立共同基础。"

#### 3. 故事线组织——论证的叙事弧线（来自 §12 Narratives Beyond Arguments）

§12 提出：学术论证不仅是"事实 + 推理"——它也需要一个**叙事弧线**。

**有效叙事四要素：**
| 要素 | 研究中的体现 | 引导问题 |
|------|------------|---------|
| **主角/起点** | 你研究的初始问题或困惑 | "你的研究从什么困惑或矛盾开始的？" |
| **冲突** | 现有知识中的缺口/矛盾 | "为什么它不是显而易见的？什么因素让这个问题值得研究？" |
| **发展** | 你的论证如何推进——各步骤的递进 | "你的论证像什么类型的旅程？（推理链条/逐步揭示/从案例到一般）" |
| **解决/开放** | 你的发现——以及它开启的新问题 | "到达终点后——读者看到了什么以前没看到的东西？" |

**引导应用**："如果你的研究写成一个故事——主角是什么人/想法？他们遇到了什么障碍？主角发生了什么转变？这能帮你找到一个比'我论证 X 因为 A,B,C'更有吸引力的组织方式。"

#### 4. 段落：论证的基本建筑单元（来自 §13 Writing Paragraphs）

即使有整体结构，每个段落本身也必须完成一个微型论证。§13 将段落视为论证的基本单元：

- **每段的锚点**：段落的第一句话应告诉读者这段的核心任务（"这一段的目的是……"）
- **已知→新信息流**：段落从读者已知的起点出发，逐步引入新信息
- **段落的终结感**：段落末尾应给读者一个"到此为止，这是这一段的意义"的感觉

**引导应用**："检查你的任何一个主要段落——读者读完第一句话能猜到这段要论证什么吗？读最后一句能知道为什么这段重要吗？"

#### 5. 修改风格：从"可以理解"到"值得读"（来自 §15 Revising Style & The Ethics of Style）

§15 的核心理念：**风格不是装饰，是负责任沟通的一部分**。

**五种常见的风格问题与修复策略：**

| 问题 | 诊断 | 修复 |
|------|------|------|
| **被动语态过重** | "被理解为……"、"被认为……" | 明确行为者，除非有意的修辞选择 |
| **名词堆砌** | "文化资源的公共性缺失问题" | 解开名词串："问题在于公共性从文化资源中缺失了" |
| **主谓距离过远** | 主语在第一行，动词在第五行 | 让主语和动词尽可能靠近 |
| **抽象主语** | "这个事实本身说明了……" | 用具体行为者做主语："这种规律说明了……" → "我们看到……" |
| **"要的就是这个效果"** | 读不懂可能恰恰因为写的是模糊的思考 | 如果你没法清晰表达——你还没想清楚 |

**伦理提醒**（§15.3）：
- 在学术写作中，"如果你不解决问题，读者会以为你的思考就像你的写作一样混乱"
- "清晰写作不是单纯的形式要求——它是负责任学术行为的一部分"
- 引导研究者把风格修改视为**尊重读者**的体现：你花时间修改，是因为你不浪费读者的时间

#### 6. 视觉与文字的关系（来自 §16 Using Visuals to Communicate）

§16 区分了视觉在论证中的两种角色，研究者需要清楚区分：

| 角色 | 功能 | 示例 |
|------|------|------|
| **视觉作为证据** | 读者必须审视视觉本身来验证你的主张 | 实验结果的原始图像、数据图表的原始数据 |
| **视觉作为修辞** | 视觉帮助读者理解你的论证 | 示意图、流程图、概念图、被简化/注释过的图表 |

**关键原则**：
- 如果读者不审视视觉**本身**就无法接受你的主张——这是证据性视觉。必须足够清晰、完整、可复制
- 如果视觉只是帮助读者跟上你的文字论证——这是修辞性视觉。可以简化，但不要扭曲
- "最糟糕的图表是那些既不作为有效证据也不作为有效修辞的图表——它们只是填补空间"

**引导应用**："你视觉里的关键信息是什么——如果去掉它，读者还能完全理解你的论证吗？如果能，那它只是修辞性的。如果不能，它必须是证据性的。"

#### 7. 口头报告与传统论文的不同逻辑（来自 §16 Presentations）

§16 还讨论了一个经常被忽略的差别——口头报告不是"把论文读出来"：

| 维度 | 论文 | 报告 |
|------|------|------|
| **速度** | 读者可以回看、减速 | 听众只听到一次 |
| **密度** | 可以密集论证 | 必须降低一半以上的密度 |
| **支持** | 引用、脚注、附录补充 | 支持在幻灯片和您的口头表述中 |
| **参与** | 读者自己决定节奏 | 听众的注意力无法控制 |

**引导原则**：
- 口头报告的核心不是"涵盖所有内容"——而是"让听众带走一个核心概念"
- "一个报告如果能让我用一个句子说清楚你做了什么——这就成功了"
- 如果报告者在 30 秒内不能说清自己的核心主张——他们还没有准备好做报告

#### 8. 交付维度与创造性研究的整合

这些交付层面的内容（Ch 10-16）与本 skill 的创造性研究引导不是分离的：

> **写作帮助思考**（§10）：鼓励研究者在思考过程中就开始写作——不仅是"写完报告"，也在写作中发现新的联系和缺口
> **组织反映了思维**（§11-13）：组织混乱往往反映了论证的混乱——帮助研究者检查结构即检查推理
> **风格体现了尊重**（§15）：引导研究者把清晰视为对读者的道德责任
> **视觉可以是论证的一部分**（§16）：视觉设计决策影响读者如何理解你的论证

**引导应用**：如果研究者卡在"表达"阶段，检查是否是因为他们还没有想清楚——而不是"写不出来"。用"用一句话告诉我你最想说的"来帮助他们提炼核心——然后一起构建围绕它的论证。

### 3.2 兜底策略

| 卡住场景 | 策略 |
|---------|------|
| "我不知道我感兴趣什么" | "最近你读到/看到/学到什么让你感到好奇或困惑的事？哪怕很小的事。" |
| "我的问题太大了" | "如果让你只回答其中一小部分，你最想回答哪个具体问题？" |
| "我觉得没什么创新点" | "那我们来试试 §4.3 的扫查：你同意谁的什么观点？不同意谁的什么观点？" |
| "我想不到有什么意义" | "先不说意义。我们来用 'So What?' 级联："如果回答了这个问题，然后呢？"逐层直到说到你不卡壳为止。" |
| "我不知道读者是谁" | "想象你在参加一个学术会议，台下是你领域的研究者。你会对他们说什么？" |
| "最怕同行说'我不在乎'" | "那我们就先检查这个问题：除了你自己，还有谁会在意？如果我们能找到至少一个在意它的同行，就不是 '我不在乎' 了。" |
| "我的论证很弱" | "你说服自己了吗？你最怀疑自己的哪个点？" |

### 3.3 关键对话框架："So What?" 深度级联

这是 skill 最重要的单一工具。每次使用应深入 3–5 层：

**第一层**："我想回答 Q1（具体问题）。" → "所以呢？"
**第二层**："回答了 Q1，它就能帮我回答 Q2（更重要的问题）。" → "所以呢？"
**第三层**："理解了 Q2，我们就能重新思考 Y（某种根本信念/实践）。" → "所以呢？"
**第四层**："重新思考 Y 可能会影响实践/政策/理论 Z。" → "所以呢？"
**第五层**：（研究者自然停止——已经足够具体和有说服力）

**原理**（来自 §2.1.3）：概念性问题总是以 Q1→Q2 结构运作。Q1 的答案之所以重要，是因为它帮助你回答一个**更重要的问题** Q2。'So What?' 级联本质上就是逐层揭示这个链——直到你触达一个不再需要追问"所以呢"的终点。

#### 3.3.1 意义的层次标尺（来自 §6.2.2）

"级联"过程中，帮助研究者定位他们的预期贡献属于哪一层次：

| 层次 | 本质 | 引导判断 |
|------|------|---------|
| **1. 新信息** | 提供新事实，无需改变既有信念 | "你只是提供了新事实，还是挑战了什么？" |
| **2. 解决困惑** | 解决领域内的矛盾或不确定性 | "你的研究解决了什么悬而未决的争论？" |
| **3. 颠覆稳固信念** | 挑战长期信奉的基本假设 | "如果是对的，会动摇这个领域的什么基础？" |

**两个关键提醒**：
- "即使是很小的发现，只要能挑战现有知识或提出新的问题，也可能具有重要意义。"（§6.2.2）
- 对刚入门的研究者：意义不是从零与诺奖级工作竞争。用"没读你的研究前你是怎么想的？它的回答改变了你多少？现在你理解了哪些以前不理解的东西？"来衡量，就是为未来回答"我为什么要在乎？"做的最好准备。（§6.2.2）

### 3.4 创新性自检引擎

当研究者已经有了初步的研究构思（经过维度一~三的对话后），可引导他们使用下面的五步自检框架。这不是"评分"工具，而是帮研究者发现薄弱环节的诊断工具。

每一步对应一个核心问题。研究者应能自信地回答每一步，否则回到对应的维度深化。

```
Step 1 ── 定位：我在和谁对话？
检查项：
  □ 我能说清这个对话在讨论什么核心问题
  □ 我知道2-3个关键参与者的立场
  □ 我的研究是对某个已有说法的回应
如果有一个"否" → 回到 维度一
```

```
Step 2 ── 意义：为什么有人应该在乎？
检查项：
  □ 我能自然回答"So What?"至少2层
  □ 我知道受众当前怎么理解这个问题
  □ 我的研究会改变他们的理解——不是"增加信息"而是"改变看法"
如果有一个"否" → 回到 So What? 级联 / 意义层次标尺
```

```
Step 3 ── 论证拉力测试：我最薄弱的那步推理在哪？
检查项：
  □ 我能区分理由（推理断言）和证据（具体事实）
  □ 每个理由都有足够的证据支撑
  □ 我能说出最可能被质疑的2个地方
  □ 我知道一个可能的反例或替代解释
如果有一个"否" → 回到 维度三
```

```
Step 4 ── 受众校准：谁会反对？为什么？
检查项：
  □ 我能从反对者的角度重述我的核心论证
  □ 我知道同行最可能质疑什么
  □ 我的论证对怀疑者也有说服力
如果有一个"否" → 回到 维度三
```

```
Step 5 ── 研究后果：然后呢？
检查项：
  □ 如果被接受，接下来最有趣的新问题是什么？
  □ 我的研究有什么局限？指向什么未来方向？
  □ 除了学术价值，对谁有实际/伦理意义？
如果有一个"否" → 回到 维度五
```

**怎么用**：
- 这不是一次性的"质量门"。不同阶段都可以拿它过一遍。
- 哪一步卡住了别跳过——回去找对应维度再聊聊。
- 刚入门的研究者，先走 Step 1–3 就够了。Step 4–5 等更成熟再说。

## 4. 可以产出什么

### 4.1 研究笔记（持续记录）

对话过程中，skill 记录关键产出，形成持续更新的研究笔记。研究者可随时要求查看当前笔记。

- 研究问题
- 创造性切入点（同意/异议/扩展）
- 论证骨架
- 潜在挑战
- 下一步问题

研究者可指定保存路径。默认：当前工作目录的 `research-notes/`。

## 5. 边界与协作

### 5.1 设计边界

| 边界 | 说明 |
|------|------|
| **不做文献搜索的执行** | 提供搜索策略和评估框架（Ch 3），但实际的数据库搜索由 nature-citation / nature-academic-search 执行 |
| **不做综述** | 不总结领域现状（可引导研究者说他们已知的） |
| **不评价想法对错** | 只帮结构化、清晰化、质疑化 |
| **不代替撰写论文正文** | 提供写作规划和风格指导（Ch 10-15），但实际撰文由 nature-writing 执行 |
| **不提供参考文献** | 除非研究者自己提到 |
| **不设对话上限** | 研究是持续过程，随理解深化而演进 |

### 5.2 与其他 skill 的协作

```
craft-of-research (发现关键问题 + 构建论证 + 规划交付)
    │
    ├──→ nature-citation (文献搜索的实际执行)
    ├──→ nature-writing (论文撰写的实际执行)
    ├──→ nature-figure (图表制作的技术实现)
    ├──→ nature-polishing (语言精修)
    └──→ brainstorming (如果研究需要构建软件/实验系统)
```

## 7. 怎么算成功

成功的标志不是"产出了一份计划"，而是研究者在对话中经历了以下转变：

- [ ] 从"我想研究 X"变成了"我想回答 Y 问题，因为它的答案会改变我们对 Z 的理解"
- [ ] 能说清楚自己的研究在学术对话中的位置（同意什么/反对什么/扩展什么）
- [ ] 对自己的论证有压力测试意识——知道哪儿最薄弱
- [ ] 能回答"所以呢？"——不是为了应付谁，而是真明白自己为什么重要
- [ ] 能提出**新问题**——不只他们自己要回答的那个，还有他们的研究会催生的那些

### 9.3 设计定位总结

本 skill 覆盖了全书（除附录作为实用指南外）的全部核心内容，但以**创造性研究引导**为组织逻辑进行重构：

**在范围内**：
- 研究作为对话的整体哲学（Preface, Ch 18）
- 创造性研究问题发现（Ch 1-4）
- 论证的结构化思考与信心建立（Ch 5-9, 含 Ethos）
- 写作作为思考工具（Ch 10-15, 含规划、组织、叙事、段落、风格）
- 视觉与表达（Ch 16）
- 研究伦理（Ch 17）
- 引言与结论的思考框架（Ch 14）

**协作关系**（与专门 skill 的关系从"排除"变为"补充"）：
- 文献搜索的实践执行 → nature-citation / nature-academic-search
- 论文正文撰写 → nature-writing
- 图表制作的技术实现 → nature-figure
- 语言精修 → nature-polishing
